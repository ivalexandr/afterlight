# AFTERLIGHT

An interactive journey into the far future of the Universe. Built with TypeScript, Vite and Three.js.

## Development

```bash
npm install
npm run dev
npm run build
```

## Publishing

The included GitHub Actions workflow builds and deploys to GitHub Pages. In repository **Settings → Pages → Build and deployment**, choose **GitHub Actions**. The public URL will be https://ivalexandr.github.io/afterlight/.

## Scientific notes

The timeline is an educational visualization, **not** a deterministic prediction. Times are approximate orders of magnitude. The fate of proton decay is unknown; black-hole evaporation assumes standard semiclassical Hawking radiation. Dark energy and cosmological expansion are assumed to continue broadly as in the standard ΛCDM model. The universe has no known finite 'heat death date'.

### Starting points for further reading

- [Adams & Laughlin (1997), *A Dying Universe*](https://arxiv.org/abs/astro-ph/9701131)
- [NASA — The Fate of the Universe](https://science.nasa.gov/universe/overview/)
- [Hawking (1974), Black hole explosions?](https://www.nature.com/articles/248030a0)

The graphics are procedural and generated at runtime; no third-party image assets are used.
